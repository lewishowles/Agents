# ChatGPT setup

This is an optional, advanced setup for connecting ChatGPT to this repository.

ChatGPT reads skills live through the [Local Repo Gateway](../servers/local-repo-gateway/README.md) rather than an uploaded knowledge base. Set up the gateway first.

## Add the system instructions

Paste the contents of `dist/chatgpt/INSTRUCTIONS.md` into your Custom GPT's system prompt, or into ChatGPT's custom instructions. The file is regenerated by `scripts/sync.sh`.

Once the gateway is connected, you can reference skills explicitly or let ChatGPT retrieve them automatically:

- _"Use my vue and code-style skills."_ Explicit requests are the most reliable.
- _"Use my skills."_ ChatGPT calls `list_skills`, determines which skills are relevant, and calls `read_skill` for each.

Re-paste the system prompt after running `scripts/sync.sh` if `src/fragments/chatgpt/system.md` changes.
