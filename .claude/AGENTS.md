# Central Agent Configuration Repository

Source of truth for Claude Code + OpenAI Codex CLI global configuration. Skills, hooks, and rules live here and are distributed to `~/.claude/` and `~/.agents/` via symlinks.

## Purpose

Single source for shared rules and skills. `scripts/sync-external-skills.sh` refreshes managed official skills; `scripts/sync.sh` composes agent-specific output files (`dist/claude/CLAUDE.md`, `dist/codex/AGENTS.md`) from content in `rules/`.

## Symlink topology (after `setup-global.sh --both`)

```
~/.claude/CLAUDE.md         → repo/dist/claude/CLAUDE.md
~/.claude/settings.json     → repo/dist/claude/settings.json
~/.claude/skills/<name>     → repo/skills/<name>         (per-skill)
~/.claude/hooks/<file>      → repo/dist/claude/hooks/<file>  (per-hook)
~/.agents/AGENTS.md          → repo/dist/codex/AGENTS.md
~/.agents/skills/<name>      → repo/skills/<name>         (per-skill)
repo/.agents/skills/agent-config → repo/.claude/skills/agent-config (repo-local)
```

## Confirmed Codex behaviour

- **Global rules:** `~/.agents/AGENTS.md`
- **Project rules:** walks root → cwd for `AGENTS.md`; root real file or symlink covers both runtimes
- **Skills:** `~/.agents/skills/` for this machine's global shared skills; frontmatter `name`+`description` visible upfront; full skill loaded on use
- **Skill discovery:** description-driven, not slash-command; `Use this skill when` plus action-led wording and file globs in description = better matching
- **Hooks:** Codex hooks exist but parity is out of scope; skill descriptions carry discovery weight instead

## Edit workflow

Edit source files here in the repo. Symlinks propagate immediately. After editing `rules/` or `dist/<agent>/source/` content, run `scripts/sync.sh` to regenerate `dist/claude/CLAUDE.md` and `dist/codex/AGENTS.md`. Run `scripts/sync-external-skills.sh` to refresh managed official skills. Commit changes here.

Don't edit `~/.claude/` or `~/.agents/` directly — changes won't persist.

## Skill structure

Shared global skills: `skills/<name>/SKILL.md` with frontmatter (`name`, `description`, `related-skills`). Descriptions for shared skills are written for both Claude auto-trigger and Codex description-driven discovery — `Use this skill when` prefix, action-led wording, file globs inline.

Managed external skills also live under `skills/<name>`, but are listed in `external-skills.json` and include `SYNC.md`. Do not edit their `SKILL.md` files directly.

## Adding a skill

1. Create `skills/<name>/SKILL.md`
2. Frontmatter: `name`, `description` (`Use this skill when` + action-led wording + globs), `related-skills`
3. Write content
4. Update `dist/claude/hooks/skill-autotrigger.sh` and `dist/claude/hooks/skill-file-trigger.sh`
5. Re-run `setup-global.sh` to create new symlinks
